# Issie v6

Summer 2026 was used to polish Issie, and fix an accumulated 30 issues from the last two years.

The main focus was small convenience features for a more intuitive easier to use user interface:

- Highlight components and wires from waveform simulator waveform labels
- Add waves to waveform simulator from schematic components or wires
- Pin the sheet menu design hierarchy for browsing big designs
- Component keyword search in catalog
- Better auto-routing of wires
- Paste vertical or horizontal arrays of a selected part of the circuit

In addition we have some new features for large designs:

- Libraries, created by users, to make components with parameters accessible from catalog like built-ins
- Array sheet components (similar functionality to Verilog for loops) for large regular designs
- Simulator 30X faster, with 10X more memory
- Better performance for designs with multiple imstances of sheets that expand to very large designs
