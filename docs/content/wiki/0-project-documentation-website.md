Issie project documentation includes static web pages & the Issie API auto-generated from the F# source.

The documentation is generated by [fsdocs](https://fsprojects.github.io/FSharp.Formatting/) which is used to [deploy the generated documentation website to github pages](https://fsprojects.github.io/FSharp.Formatting/zero-to-hero.html).

* `fsdocs` is configured to look for markdown `*.md` files anywhere in the `./docs` subtree and translate them into equivalent `*.html` files making a static website. 
* Template files under `./docs` root can be used to format all of the pages.
* Every markdown file has a header which determines its position in the auto-generated navigation pane and maybe (not sure if `page: pageFormat` header lines work?) its individual format.

## Maintaining Documentation

Github will need a new SSL personal access token as documented in the workflow from time to time.

The certificate can be updated from:

* Issie -> Settings -> Secrets and variables -> update ISSIE_DOCS_TOKEN

See workflow file for how to generate a new token

```
# A new personal access token must be generated to allow the GitHub Actions workflow to push to the repository.
# The token must have the 'repo' scope.
# Generate here https://github.com/settings/tokens/new
# Add the token to the repository secrets as ISSIE_DOCS_TOKEN
# https://docs.github.com/en/actions/reference/encrypted-secrets#creating-encrypted-secrets-for-a-repository
```
