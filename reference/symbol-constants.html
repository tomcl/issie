arrayLegendFontSizeInPixels

Full Usage: arrayLegendFontSizeInPixels

Returns: float

Font size for the legend of an array component's IO. Smaller and lighter than any other legend, and on one line: these say a name, a channel and a bit range - "Join[3] (15:0)" - where an ordinary legend is a word. Set here rather than at either use because getComponentProperties sizes the symbol with this style and SymbolView draws with it, and a symbol sized against a different font is one the text runs out of.

Returns: float
