# Contributing to Issie


* See the Issie `Info --> Bug Reports` for information about how to report a possible bug in an Issie issue
* There is an automatic test suite: `npm run test` runs about 129 tests in 20 seconds. Run it before you make a PR, and add to it — see [Tests/README.md](Tests/README.md)
* **CI does not run those tests**, on any platform: it only checks that the app still compiles. So passing CI says very little. In your PR, say how much you have tested the change, or why you think it won't break anything
* If you are writing new code take to heart the extensive [Issie coding guidelines](https://github.com/tomcl/issie/wiki/Coding-guidelines-for-ISSIE)
